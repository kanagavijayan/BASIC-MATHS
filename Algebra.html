Algebra

Algebra is the branch of mathematics that uses symbols (usually letters) to represent unknown values, called variables, and combines them with known values (constants) through operations like addition, subtraction, multiplication, and division. It’s essentially a way of solving puzzles where the goal is to find the value of the unknown.

🔹 Core Ideas of Algebra

  • Variables: Letters such as 𝑥,𝑦, or 𝑧 that stand for unknown numbers.
  • Constants: Fixed numbers that don’t change.
  • Expressions: Combinations of variables and constants using operations (e.g., 3𝑥+5).
  • Equations: Statements showing equality between two expressions (e.g., 𝑥+2=7).
  • Inequalities: Comparisons using symbols like >,<,≥,≤.

✨ Basic Rules

  • Balance Principle: Whatever you do to one side of an equation, you must do to the other side.
  • Order of Operations (BODMAS): Brackets → Orders (exponents/roots) → Division → Multiplication → Addition → Subtraction.
  • Inverse Operations: Use opposites to isolate variables (e.g., subtract to undo addition).

📊 Simple Examples

  • Solve 𝑥−2=4: Add 2 to both sides →𝑥=6.
  • Solve 𝑥+5=12: Subtract 5 from both sides → 𝑥=7.
  • Expression 2𝑥+3: If 𝑥=4, then 2(4)+3=11.
